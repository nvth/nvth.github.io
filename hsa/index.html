03 HIGH · 8.7

Stored XSS through uploaded SVG files in PrestaShop

prestashop/prestashop · Composer

GHSA-99cp-c6mm-p7h5 CVE issued: Pending

A back-office employee with permission to use the file manager, including the product editor, or the logo uploader could upload an SVG containing JavaScript. Because the file was served from the shop's own origin, opening it by a more privileged employee executed the script in that employee's back-office session, allowing actions on their behalf and potentially taking over an administrator account.
